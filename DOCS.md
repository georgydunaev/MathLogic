# Propositional Logic Implementation

This file documents the implementation of propositional logic in the `Propositional.v` file.

## Definitions

- **AtomVars**: Definition for atomic variables, represented as natural numbers.
- **Fo**: Inductive type for formulas in propositional logic.
- **Valuations**: Definition for valuations, which map atomic variables to boolean values.

## Functions

- **foIb**: Function to evaluate a formula given a valuation.

## Notations

- `-/\`: Conjunction of two formulas.
- `-/\`: Disjunction of two formulas.
- `-->`: Implication between two formulas.

## Top-Level Proposition

- **Top**: Definition for the true proposition, which is the implication of `Bot` with itself.
